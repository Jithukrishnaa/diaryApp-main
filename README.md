# 📔 Diary App

A simple and intuitive **digital diary application** built primarily with TypeScript. The project provides a space for users to create, manage, and organize their personal diary entries through a clean web-based interface.

## 🌟 About the Project

**Diary App** is a personal journaling application designed to provide a simple digital alternative to maintaining a traditional diary.

Instead of writing entries in a physical notebook, users can record their thoughts, experiences, memories, and important moments digitally.

The project was developed with a focus on creating a straightforward and user-friendly diary experience.

---

## ✨ Features

* 📝 **Create Diary Entries** – Write and save personal thoughts and experiences.
* 📖 **View Entries** – Browse previously created diary entries.
* ✏️ **Edit Entries** – Update existing diary content.
* 🗑️ **Delete Entries** – Remove entries that are no longer required.
* 📅 **Organize Entries** – Keep diary content organized by date.
* 💻 **Web-Based Interface** – Access the diary through a browser.
* 🎨 **Clean User Interface** – Simple layout focused on readability and usability.
* 📱 **Responsive Design** – Designed to work across different screen sizes.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm
* A modern web browser
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/Jithukrishnaa/diaryApp-main.git
```

### 2. Navigate to the Project

```bash
cd diaryApp-main
```

If the actual application is inside the nested project folder:

```bash
cd diaryApp-main
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

Depending on the project's configured scripts, run:

```bash
npm run dev
```

or:

```bash
npm start
```

Then open the local development URL displayed in your terminal.
